Authored a technical security assessment and walkthrough for the TryHackMe "Plant Photographer" room. Performed web application reconnaissance, analyzed backend request handling, and identified multiple vulnerabilities that could be chained to achieve full application compromise. The assessment covered source code analysis, directory enumeration, HTTP parameter manipulation, information disclosure, Server-Side Request Forgery (SSRF), localhost access bypass, Werkzeug debugger analysis, PIN reconstruction, and Python-based remote code execution. Documented the exploitation process, explained the underlying security concepts, and summarized defensive recommendations and key lessons learned. This project strengthened practical skills in web application penetration testing, exploit chaining, Linux enumeration, and technical security reporting.
